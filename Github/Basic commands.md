Check if you have access
```
ssh -T git@github.com
```

Initialize a git folder
```
git init
```

Add all files in current folder
```
git add *
```

commit your files
```
git commit -m "note"
```

push your files
```
git push
```

pull down your files for the first time
```
git clone git@github.com:cashbystone/ispyagentdvr.git --branch master
```
